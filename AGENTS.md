# Regras do projeto Authentic Glitch

Este repositorio e independente de outros projetos. Nao transportar identidade visual, regras de negocio, conteudo, estrutura ou decisoes de outros repositorios sem validacao explicita.

Antes de editar:
1. ler `PROJECT.md` e `docs/STATUS.md`;
2. localizar somente os arquivos ligados a tarefa;
3. preservar a estrutura atual quando nao houver motivo para refatorar;
4. diferenciar fatos confirmados de sugestoes e inferencias;
5. nao inventar conteudo institucional.

Antes de encerrar uma sessao relevante, atualizar `docs/STATUS.md` e `docs/SESSION.md`.

Nao versionar credenciais, tokens, dados privados ou arquivos temporarios.
